# Payaskan Sarpudeen — QC Portfolio

This is a static portfolio website built from the information in the supplied resume.

## Files
- `index.html` — website
- `style.css` — responsive styling
- `script.js` — theme toggle, mobile menu and reveal animations
- `assets/payas-profile.png` — professional photo extracted from the supplied resume
- `assets/PayasKan-Resume.pdf` — supplied resume for the Download CV button

## GitHub Pages
1. Create a new GitHub repository, for example `payas-portfolio`.
2. Upload the contents of this folder (not the ZIP itself).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the live website URL.

## Before publishing
Review the phone number, email and LinkedIn URL because they will be publicly visible on the website.
